## 注意
これは実験用として自分用に作ったものです。

## 準備
jarと同じフォルダに```assets```フォルダを置き、以下のような名前のファイルを置いてください。
```
touhou.jar
assets/bgm.wav
       pichuun.wav
       fran.png
       reimu.png
       testx.txt
       testy.txt
```
```bgm.wav```はBGMです。適当な音楽を入れてください。<br>
```pichuun.wav```は被弾音です。適当な効果音を置いてください。<br>
```fran.png```はボスの画像です。背景は透過している方が良く、解像度は関係ありません。<br>
```reimu.png```は自機の画像です。```fran.png```と同様、背景は透過している方が良く、解像度は関係ありません。<br>
```testx.txt```, ```testy.txt```は弾幕の軌道をx,y座標別に記述するファイルです。開発の都合上このファイル名になっています。<br>
```testx.txt```, ```testy.txt```の文法は以下の通りです。
- 最初に引数を宣言します。（この場合は```t,r>```に固定）
- 次に数式を記述します。
  - 英大文字だけの「演算子」、その他の文字で構成された「数値」を交互に表して数式を表現します。
  - 演算子は、受け取った数値と、直後の数値を引数にとって、1つ後の演算子に数値を渡します。
  - 前に何もない時、演算子は0を受け取ります。
  - 演算子とその渡す数値は以下に一覧として示します。受け取った数値をa, 直後の数値をbとします。
    - ```AD``` a+b
    - ```SB``` a-b
    - ```MT``` a*b
    - ```DV``` a/b
    - ```MD``` a mod b
    - ```RT``` a^(1/b)
    - ```PW``` a^b
    - ```SN``` sin(b)
    - ```CS``` cos(b)
    - ```TN``` tan(b)
    - ```LG``` log_b (a)
    - ```AS``` arcsin(b)
    - ```AC``` arccos(b)
    - ```AT``` arctan(b)
    - ```AB``` |b|
    - ```FL``` floor(b)
    - ```CL``` ceil(b)
    - ```SG``` sign(b)
    - ```SH``` sinh(b)
    - ```CH``` cosh(b)
    - ```TH``` tanh(b)
    - ```CC``` cosec(b)
    - ```SC``` sec(b)
    - ```CT``` cot(b)
    - ```MW``` 変数のような機能です。変数のインデックス番号bに数値aを代入し、aを後ろの演算子に渡します。後から数値として取り出すには、インデックス番号の直前に```:```と入力します。（例：```:3```）
  - 数値には、整数、小数、最初に宣言した引数、先述した```:```が使えます。

以下はそのまま弾幕として動くサンプルです。<br>
testx.txt<br>
```t,r>ADrDVtAD1MW0CS:0MTtMT50``` <br>
testy.txt<br>
```t,r>ADrDVtAD1MW0SN:0MTtMT50``` <br>
### 数式を記述する上での注意
- ボスは1秒（60フレーム）毎に弾幕を発射し、その度に移動するので、それも考慮して弾幕を作る必要があります。
- ボスの中心座標がこの数式の原点です。
- ボスの挙動まで指定できるバージョンも出す予定です。

## 操作方法
東方の原作と同じです。<br>
- zキー：弾の発射
- shiftキー：低速移動
- 矢印キー：移動
